# Dispatch AI — MVP Prototype

A working prototype of the AI chat/call agent platform: a landing page with a live AI chat demo, a client intake form, an AI script generator, and a review/approve dashboard.

## What's actually working right now

The landing page (`/`) has a real chat widget wired to Claude, plus a visible pricing section. The intake form (`/onboard`) saves a new client and calls Claude to draft their agent's script from the answers. The dashboard (`/dashboard`) lists every client, lets you edit the draft script, approve it, and generate a real Stripe subscription payment link to send to that client. The dashboard is protected by a login (HTTP Basic Auth), and Stripe webhooks automatically keep each client's status in sync — flipping to "paid" the moment they complete checkout, and to "cancelled" the moment their subscription actually ends, with no manual checking required either way.

Cancellation is self-service for your clients, not just you: after paying, a client lands on `/success`, which has a "Manage my subscription" button opening Stripe's own Customer Portal — from there they can cancel, update their card, or view invoices themselves, with no email or phone call to you required. You can also generate that same portal link for any paid client at any time from a button on their dashboard card, for cases where they reach out to you directly instead. Everything runs as a single Node.js process with **zero npm dependencies** — no `npm install` step is required to run it, only Node.js itself (version 18 or newer).

Without an `ANTHROPIC_API_KEY` set, the app runs in "demo mode": every AI response is a canned placeholder, but the entire flow (forms, saving, dashboard, editing, approving) is fully testable. Without a `STRIPE_SECRET_KEY` set, the payment link buttons show a demo-mode message instead of a real link. Both fallbacks, plus the dashboard login and the webhook signature verification, were tested end-to-end before this file was handed to you.

## Running it locally

1. Install Node.js 18+ if you don't have it (nodejs.org).
2. Open a terminal in this folder.
3. Copy `.env.example` to `.env` and fill in `ANTHROPIC_API_KEY` (get one at console.anthropic.com) to get real AI responses instead of placeholders.
4. Run `node server.js`.
5. Open `http://localhost:3000` in a browser.

## What's NOT built yet (by design, for an MVP)

There's no real database (client data lives in `data/clients.json` — fine for testing and your first handful of clients, not for scale). The dashboard login uses a single shared username/password rather than per-user accounts — fine for one founder, not for a team. Clients don't have their own login either — the self-service subscription portal works via a link (from their post-payment page, or generated by you on demand), not a persistent account they can log back into whenever they want. There's no live phone number yet — `scripts/create-retell-agent.js` is a ready-to-run helper for connecting an approved script to Retell AI once you have a Retell account, but it's a manual step, not automatic yet. A cancelled subscription correctly flips a client's status to "cancelled" in the dashboard, but it doesn't yet automatically pause anything in Retell — once a client has a real phone number connected, cancellation still needs a manual step to actually take their agent offline (a good next addition once Retell is wired up for real). Note that the self-service portal itself requires a one-time toggle in Stripe's own dashboard (see LAUNCH_CHECKLIST.md Step 6) — without it, the "Manage my subscription" button will show an error instead of opening the portal.

## File guide

`server.js` is the entire backend — routes, static file serving, dashboard auth, Stripe checkout and webhook handling, all in one file for easy reading. `lib/claude.js` calls the Anthropic API (and falls back to placeholder text if no key is set). `lib/stripeClient.js` creates Stripe Checkout sessions and verifies webhook signatures, using plain `fetch` and Node's built-in `crypto` (no Stripe SDK dependency). `lib/scriptPrompt.js` builds the prompt that turns intake answers into a draft script — this is the actual "product" logic worth iterating on as you learn what makes a good script. `lib/db.js` is the JSON-file storage. `public/` has the three pages (landing, onboard, dashboard) as plain HTML/CSS/JS — no framework, no build step. `scripts/create-retell-agent.js` pushes an approved script live to Retell AI (run manually, not from the dashboard).

See `LAUNCH_CHECKLIST.md` for the non-technical, step-by-step path from this code to a real URL real customers can use.
